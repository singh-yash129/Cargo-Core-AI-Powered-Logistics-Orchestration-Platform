
# Login Signup Flow Design

This is a code bundle for Login Signup Flow Design. The original project is available at https://www.figma.com/design/f3M3ET9UB2kDl1igTCwWsT/Login-Signup-Flow-Design.

The backend-integrated web frontend runs from the repo root.
The older legacy/mock frontend has been moved to `dummy-frontend/`.
The mobile driver app lives in `driver-app/`.

## Running the code

Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
