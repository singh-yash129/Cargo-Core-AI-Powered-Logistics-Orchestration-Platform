# ADB Device Connection

## Steps

1. Plug in USB cable to phone
2. Enable Developer Mode + USB Debugging on phone
3. Open **Git Bash** or **Android Studio terminal**
4. Run:

```
"C:\Users\pruth\AppData\Local\Android\Sdk\platform-tools\adb.exe" devices
```

5. Phone should show as `device` (not `unauthorized`)
6. Hit **Run** in Android Studio
