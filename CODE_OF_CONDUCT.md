# 📘 Code of Conduct

## 1. Respect and Collaboration
- Treat all contributors, instructors, and reviewers with professionalism and courtesy.  
- Encourage constructive feedback during code reviews and discussions.  
- Avoid discriminatory, offensive, or disrespectful language in commits, documentation, or communication.  

## 2. Academic Integrity
- Submit only original work; plagiarism or unauthorized copying is strictly prohibited.  
- Cite external references or libraries clearly in documentation.  
- Do not share project code outside approved IIT Madras academic channels.  

## 3. Responsible Contribution
- Follow repository structure, commit guidelines, and documentation standards.  
- Ensure code is tested and reviewed before merging.  
- Report bugs, issues, or risks transparently rather than concealing them.  

## 4. Licensing and Usage
- This project is licensed for **academic use only** under IIT Madras guidelines.  
- Commercial use, redistribution, or hosting outside approved platforms is forbidden.  
- Respect intellectual property rights of all contributors.  

## 5. Safety and Reliability
- Prioritize secure coding practices and avoid introducing vulnerabilities.  
- Use genuine, verified dependencies and avoid unsafe shortcuts.  
- Document risks and limitations clearly for users and reviewers.  

## 6. Accountability
- Violations of this Code of Conduct may result in removal from the project, academic penalties, or disciplinary action.  
- Contributors are responsible for maintaining transparency in their work and communication.
