# User Feedback

## Primary Users
Users who directly interact with the Cargo-Core software are considered primary users.  
The primary user roles present in our system are:

- Warehouse Manager  
- Dispatcher  
- Driver  

---

### 1. Warehouse Manager
**Feedback Summary:**  
The Manager is highly satisfied with the software's design and components. They requested one minor feature update: because their local logistics department sometimes operates out of multi-level warehouses, they would like **multi-floor planning capabilities** added to the 2D Warehouse Mapping module. Overall, the Manager was very impressed with the system's current capabilities.

---

### 2. Dispatcher
**Feedback Summary:**  
The Dispatcher reviewed the system thoroughly and provided positive feedback, along with a key usability suggestion for the live-tracking map.  

Currently, hovering over a delivery vehicle on the map only displays the vehicle and license numbers in the tooltip. To find the driver, the Dispatcher has to navigate to a different page and search using those numbers.  

To improve efficiency, the Dispatcher suggested expanding the map tooltip data to include:
- Driver name  
- Standard delivery metrics: total number of orders, orders delivered, and orders pending  
- For house-shift/moving jobs: driver name, checklist status, arrival status at the destination, and overall work progress  

---

### 3. Driver
**Feedback Summary:**  
The Driver appreciated the system's design and usability. To ensure the software does not interrupt their workflow and allows them to provide quick service, they offered two suggestions:

- Implement simple, minimal password requirements (or an easier login method) so it is quick to type and remember.  
- Extend the session timeout so that once they log in at the start of their morning shift, they do not need to log in again while out on a service run.  

*(Note: We discussed these workflow suggestions with the Dispatcher, who agreed they are necessary for field efficiency. The Dispatcher will escalate this password policy request to the Logistics Manager for approval, as the Manager handles system credentials)*

---

## Conclusion
These feedback points and suggestions from our primary users will be implemented in the **Milestone 4 deliverables**, scheduled for completion by **April 14, 2026**.
